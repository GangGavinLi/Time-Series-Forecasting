**Time Series Forecasting**

Course notebooks for a Special Topics course on Time Series Forecasting at Mississippi State University.

This course explores modern time series analysis, feature extraction, decomposition, and forecasting methodologies using Python. This repository contains lecture notebooks, tutorials, and practical examples designed to bridge foundational statistical theory with modern computational workflows in time series modeling. Each module is a self-contained Jupyter notebook that pairs the conceptual material with runnable Python. 

**Instructor:** Gang Li, PhD, Mississippi State University
